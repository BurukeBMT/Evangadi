## 🚀 Getting Started

### 📋 Prerequisites

Before you begin, ensure you have the following installed:

- ✅ [Node.js](https://nodejs.org/) (v14 or higher)
- ✅ [npm](https://www.npmjs.com/) or [yarn](https://yarnpkg.com/)
- ✅ [Git](https://git-scm.com/)
- ✅ [MySQL](https://www.mysql.com/) (for backend projects)
- ✅ [VS Code](https://code.visualstudio.com/) (recommended)

### 🛠️ Installation Guide

#### Step 1: Clone the Repository
```bash
git clone <repository-url>
cd Evangadi
```

#### Step 2: Choose Your Project

Select a project based on your skill level:

| Project | Difficulty | Tech Stack | Time Estimate |
|---------|------------|------------|---------------|
| [Puppy Lovers Page](./Phase-1/Week-3/PuppyProject/) | Beginner | HTML, CSS | 2-3 hours |
| [Apple Clone](./Phase-1/Week-4/appleProject/) | Beginner | HTML, CSS | 4-6 hours |
| [DOM Manipulation](./Phase-2/Week-12/DomPopUpQuestion/) | Intermediate | JavaScript | 3-4 hours |
| [Node Server](./Phase-3/Week-15/nodeServerProject/) | Intermediate | Node.js, Express | 4-5 hours |
| [React Apple](./Phase-3/Week-17/AppleReactFunctionalComponent/) | Advanced | React | 5-7 hours |
| [Evangadi Forum](./Phase-4/Evangadi-Forum/) | Advanced | Full-Stack | 10-15 hours |
| [Netflix Clone](./Phase-4/netflix-clone-2025/) | Advanced | React, APIs | 8-12 hours |

#### Step 3: Navigate to Your Chosen Project
```bash
# Example: For Evangadi Forum
cd Phase-4/Evangadi-Forum

# Example: For Netflix Clone
cd Phase-4/netflix-clone-2025
```

#### Step 4: Install Dependencies
```bash
npm install
# or if using yarn
yarn install
```

#### Step 5: Environment Setup

Most projects require environment variables. Check for `.env.example` files:

```bash
# Copy environment template
cp .env.example .env

# Edit .env file with your credentials
nano .env  # or use your preferred editor
```

**Common Environment Variables:**
- `DATABASE_URL`: MySQL connection string
- `JWT_SECRET`: Secret key for JWT tokens
- `API_KEY`: External API keys (TMDB, Stripe, etc.)
- `PORT`: Server port (usually 3000 or 5000)

#### Step 6: Run the Application

```bash
# Development mode
npm run dev

# Production build
npm run build
npm start
```
